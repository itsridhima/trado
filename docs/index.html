Trado: a voice buddy that teaches trading and investing

Hold a hotkey, ask a question out loud, and Trado looks at your screen and answers out loud in simple words. Made with an India focus.

Download the latest release See the code on GitHub

Educational only. Not financial advice.

Trado explains ideas. It will not tell you what to buy or sell, give price targets or predictions, or plan your money, and it will never click or type anything for you. It is not a SEBI-registered investment adviser and is not linked to SEBI, NSE, BSE or any broker. It can be wrong, so check facts with official sources. For personal decisions, talk to a SEBI-registered investment adviser.

How it works

  1. Hold Ctrl + Left Alt and speak (you hear a short beep when the mic is ready).
  2. Your words are turned into text.
  3. Trado looks at the screen under your mouse, and asks a vision AI about it.
  4. You read the answer and hear it spoken. Press the hotkey again any time to interrupt.

Not built yet: conversation memory, the glowing pointing cursor, a trading knowledge base and a one-click installer.

What you need

  • Windows 10 or 11, a microphone and an internet connection
  • Python 3.11 or newer (tick "Add python.exe to PATH" when installing)
  • A free Groq API key. The free plan allows only a few questions per minute.

Trado is a program that runs on your own PC, so it cannot run inside this web page. It needs your microphone, your screen and a hotkey.

Set it up (Windows PowerShell)

git clone https://github.com/itsridhima/trado.git
cd trado
python -m venv venv
.\venv\Scripts\Activate.ps1
pip install -r requirements.txt
python -m trado --setup     # paste your Groq key; the screen stays hidden
python -m trado

Prefer no Git? Download the source zip from the releases page, unzip it, and start at the python -m venv venv line.

Full instructions and every setting are in the README.

Privacy and limits

  • Your voice and a screenshot leave your computer. They go to Groq, using your own key. Trado keeps audio and screenshots in memory only and never saves them. Groq's own terms apply, and its free plan may store data, so don't say or show private details.
  • Before sending a screenshot of a login, KYC, bank or broker page, Trado asks you first (default answer: No). It only reads the title of the front window, so it can miss things.
  • Things that look like a PAN, Aadhaar, card number, phone number, OTP or password are hidden before the AI sees your question. Your voice clip is uploaded first, so still don't say them aloud.
  • No analytics and no tracking. Trado sends nothing anywhere except to Groq.
  • English only for now, with a built-in Windows voice that sounds robotic.
